Preferences

About Blank

Opens Galaxy OS in a separate window titled about:blank

Blob

Opens Galaxy OS in a separate window with a neutral title

Quick key

Press this key anywhere in Galaxy OS (not while typing in a text box) to open a website in the Browser. Add Ctrl or Alt if you want it to also work while a website is focused.

Anti-Close

Shows a "Changes you made may not be saved" prompt before the window closes

Browser

Browser style

Glass makes the Browser translucent and blurred so your wallpaper shows through. Theme uses the solid colours of your selected theme.

Taskbar

Position

Where the taskbar sits on the screen

Icon size

Make the taskbar icons smaller or larger

Arrange apps

Drag taskbar icons to move them to the left, middle or right of the taskbar. Drop one icon onto another to make a folder (click a folder to open it). Right-click the taskbar for more.

Window animations

Windows fade in when opened, fly to the taskbar icon when minimized and fade out when closed

Shortcuts

App shortcut

Pick an app, click the key box and press the keys you want. Press that shortcut anywhere in Galaxy OS to open the app. Combos with Alt or Ctrl also work while a website is focused.

Your shortcuts

Defaults: Alt + S opens Settings, Alt + A opens Apps.

Jarvis

Voice assistant

Press Ctrl + H anywhere in Galaxy OS, then say what you want: "open TikTok", "close the browser", "search for cats", "change theme to violet", "next wallpaper", "snap left", "what time is it". Starting with the assistant's name works too: "Jarvis, open TikTok".

Name

What you call your assistant. It answers to this name and shows it on the screen.

Spoken replies

Jarvis talks back using your computer's voices.

Listening engine

Auto tries the browser's built-in speech service and switches to the Whisper model if it is not available (Electron usually needs Whisper). Whisper downloads a small model (about 40 MB) the first time and needs an internet connection.

Proxy

Search

Change the browser's search engine

Web proxy

Built in and always on: every Browser tab, app and game link loads through this site's own proxy. If a search engine shows a captcha or a blank page, switch to another one on the left (Bing and Mojeek are the most reliable).

Themes

Chill lofi vibes~

Dynamic theme

Pull the accent color from your wallpaper automatically. Buttons, highlights, the taskbar indicator and widgets follow it, and it updates whenever you change the background. The theme you pick below still sets the surfaces.

Theme maker

Pick four colors and the whole OS changes live. Share your theme as a short code, or paste a friend's code to use theirs. Your theme appears below as "Custom".

Backgrounds

Backgrounds

Pick a wallpaper, or paste an image link

Tab cloak

Disguise the window

Changes the window title and the window / taskbar icon so Galaxy OS looks like another site. The icon is that site's own favicon, so it needs an internet connection to load (the title changes right away).

Your own

Type any title and a site (for example docs.google.com) to borrow its icon.

Boot logo

Text

What the startup and shutdown animation spells out (up to 16 characters).

Image

Upload your own logo instead of text. A PNG with a transparent background looks best. It is saved on this computer, shrunk to fit.

No image

Subtitle & preview

The small line under the logo. Leave it empty for none.

Display

Brightness

Dims the whole desktop, including websites and games. The sun button in the top bar opens the same controls.

Night light

Warms and dims the screen. Choose Schedule to turn it on and off by itself (a range like 21:00 to 07:00 runs overnight).

Fromto
Warmth
Extra dimming

Low battery alert

Shows a message when the battery runs low and the charger is not plugged in. For a live readout, add the Battery widget (right-click the desktop > Widgets > Battery).

Warn at

Data

Browsing data

Clears cookies, site storage and cache from the Browser and GeForce NOW

Export settings

Save your theme, background, taskbar, pins and preferences to a file

Import settings

Load a settings file exported from Galaxy OS on another computer

Reset settings

Restores themes, background, search engine and preferences to their defaults

About
